Solar Climate Dashboard

Dashboard interactivo para mapear datos climaticos a un calendario solar conceptual 4x90. El proyecto compara vistas solares y gregorianas, explora hemisferios, analiza drift anual y suma modulos opcionales de machine learning.

Leer ficha tecnica Ver dataset sample
Streamlit app Plotly charts Solar 4x90 engine CSV/XLSX upload ML opcional

Problema

Analizar clima solo por meses gregorianos puede ocultar patrones solares. El proyecto propone una lectura alternativa: convertir cada dia a posicion solar y comparar ambas coordenadas.

Decision tecnica

Separar motor solar, carga de datos, graficos y ML en modulos reutilizables para que el dashboard crezca sin mezclar UI, transformacion de datos y visualizacion.

Resultado

Workbench de analisis con dataset sample, subida de archivos, heatmaps, curvas comparativas, drift, exportacion y modulos opcionales de clustering, anomalias y regresion.

Arquitectura

Pipeline del dashboard

Python modular
01 Data loader

Carga CSV/XLSX, normaliza fechas, conserva columnas extra y prepara variables numericas.

02 Solar engine

Convierte fechas gregorianas a estacion solar, dia solar, offset y progreso normalizado.

03 Visualization

Genera heatmaps, curvas, comparaciones hemisfericas, scatter plots y drift anual con Plotly.

04 ML module

Ejecuta clustering, deteccion de anomalias y regresion usando features solares.
