Drone Factory

Juego incremental de fabrica de drones con economia, contratos, misiones, eventos temporales, progreso offline y telemetria local. La demo suma una consola visual de planta para comunicar el estado de produccion.

Proyecto insignia

Por que se destaca

Insignia
Madurez

Demo web directa con economia incremental, contratos, inventario y progreso offline.

Evidencia

10 tests automatizados cubren crafting, contratos, prestigio, costos y ganancia offline.

Valor portfolio

Expone sistemas de juego reales, balance, UI operativa y telemetria sin backend.

Siguiente mejora

Mejorar captura principal con una sesion avanzada y ajustar onboarding para primera visita.

Problema

La logica de juego ya existia, pero necesitaba una presentacion mas fuerte como pieza de portfolio: identidad visual, lectura rapida y una señal clara de sistema interactivo.

Decision tecnica

Mantener la arquitectura modular y sumar una capa visual conectada al estado real: canvas de planta, plan operativo, status de receta y datos de produccion.

Resultado

Demo jugable con estetica consistente al laboratorio, controles accesibles, informacion ejecutiva y documentacion tecnica lista para mostrar.

Sistemas de juego

Lo que demuestra el proyecto

Interactive systems
01 Economia incremental

Energia, EPS, compras por lotes, upgrades, prestigio, multiplicadores y progresion offline.

02 Fabrica por componentes

Estaciones, cooldowns, inventario, deficits de receta y ensamblaje de drones.

03 Retencion y objetivos

Misiones diarias, contratos, racha, onboarding, eventos temporales y recompensas.

04 Observabilidad

Telemetria local exportable, simulacion de balance y tests de sistemas clave.

Mejoras destacadas

  • Nuevo estilo oscuro verde/marron alineado al laboratorio.
  • Canvas `Factory Floor` con estaciones, stock, deficits y ensamblaje.
  • Panel de plan operativo con objetivo, EPS, contratos y evento activo.
  • Responsive mejorado para no cortar controles.
  • README tecnico y ficha de caso integrados.
