Simulador termico de disipadores

Herramienta interactiva para comparar materiales, potencia de chip, geometria de aletas y conveccion. El usuario ajusta parametros, revisa temperatura maxima, resistencia termica, masa, costo relativo y exporta un reporte tecnico del diseno.

Proyecto insignia

Por que se destaca

Insignia
Madurez

Demo tecnica navegable con presets, calculos, canvas, guardado local y reporte exportable.

Evidencia

Build Vite portable, README tecnico y captura usada como miniatura del catalogo.

Valor portfolio

Convierte parametros fisicos en feedback visual y numerico comprensible para usuarios tecnicos.

Siguiente mejora

Agregar comparacion lado a lado de dos disipadores y export PDF mas formal.

Problema

Convertir conceptos termicos en una demo explorable: el usuario debe ver como cambian temperatura, resistencia, eficiencia y costo cuando modifica el diseno fisico del disipador.

Decision tecnica

Separar calculo, visualizacion, recomendaciones, reportes y controles React. Esto deja el motor termico legible y permite mejorar cada capa sin tocar toda la aplicacion.

Resultado

Simulador navegable con presets, canvas escalable, guardado local, recomendaciones automaticas y build estatico enlazado desde el portfolio.

Modelo y producto

Lo que demuestra el proyecto

Demo tecnica interactiva
01 Motor termico

Calcula conveccion, resistencia total, eficiencia de aletas, area efectiva, masa y densidad termica.

02 Exploracion UX

Sliders, selector de material, modo natural/forzado y presets para validar escenarios frecuentes.

03 Visualizacion

Canvas 2D con mapa conceptual de temperatura, flujo de aire y perfil termico opcional.

04 Salida tecnica

Guardado local de disenos, comparacion rapida y exportacion de reporte para documentar resultados.

Mejoras destacadas

  • Presets para IoT fanless, CPU edge y GPU compacta.
  • Persistencia local de hasta 8 disenos guardados.
  • Canvas con escala dinamica para evitar cortes en aletas grandes.
  • Estetica oscura con verdes tecnicos y tonos cobre.
  • Vite configurado con rutas relativas para `dist/` portable.
