Problema

El desafio era convertir una prueba mobile de analytics en una app demostrable: cerrar el build, ordenar las capas Android y sostener la experiencia aunque el backend no este disponible.

Decision tecnica

Reconstruir una base compilable con Compose, Hilt, Retrofit, StateFlow y repositorio con fallback local para que la app siga siendo demostrable aunque el backend no este levantado.

Resultado

Build debug verificado, APK generado, dashboard navegable, filtros operativos, exportacion PDF y flujo de compartir reporte con FileProvider.

Arquitectura

Capas separadas para una demo robusta

Mobile-first analytics
01 Compose UI

Scaffold, TopAppBar, Bottom Navigation, filtros, pantallas de KPIs, insights, plataformas y predicciones.

02 ViewModel + StateFlow

Estado unico para destino activo, filtros, loading, mensajes, PDF exportado y snapshot analitico.

03 Repository

Orquesta Retrofit, fallback local, refresco de dataset y generacion de PDF si el backend no responde.

04 FastAPI contract

Endpoints para dashboard, refresh de dataset y descarga de reporte PDF desde servidor local.

Flujo de producto

  • Seleccion de plataforma, segmento y anio.
  • Dashboard con revenue, spend, ROI, conversiones y campanas.
  • Vistas separadas para plataformas, insights, KPIs y predicciones.
  • Refresco remoto con fallback local si falla la red.
  • Exportacion y share de reporte PDF.
