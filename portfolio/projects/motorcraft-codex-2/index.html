Proyecto insignia

Por que se destaca

Insignia
Madurez

Build Vite portable con escena WebGL, modo demo, validador y exportacion de evidencia.

Evidencia

Demo embebida con parametros por URL y captura real integrada al catalogo.

Valor portfolio

Muestra integracion entre 3D, UI tecnica, reglas de ingenieria y documentacion reproducible.

Siguiente mejora

Agregar casos guiados por tipo de motor y mensajes didacticos para usuarios no especialistas.

Problema

Un simulador tecnico necesita ser comprensible en segundos sin perder densidad: controles claros, feedback de validacion y una escena 3D que comunique el concepto antes de exigir configuracion manual.

Decision tecnica

Separar escena, modelos, logica electrica, validador, exportacion y UI. Vite empaqueta dependencias y deja un `dist/` portable para integrarlo al laboratorio por HTTP.

Resultado

La demo abre con bobinado prearmado, campo rotante y controles listos para experimentar. Tambien permite guardar/cargar JSON y exportar evidencias visuales.

Arquitectura

Lo que demuestra el proyecto

Simulador tecnico
01 Escena 3D modular

Renderer, camara, controles, labels, iluminacion, stator, slots y bobinas se mantienen desacoplados.

02 Modelo electrico

Configuracion de slots, polos, conexion, paso de bobina, frecuencia y fases A/B/C.

03 Validacion

Chequeos de SPP, paso de bobina, congestion de ranuras y resumen tecnico visible para el usuario.

04 Flujo portfolio

Modo demo por URL, panel de acciones rapidas, README limpio y ficha embebida en el laboratorio.

Mejoras destacadas

  • Dependencias locales via Vite, sin import map CDN.
  • Modo `?demo=1&field=1` para mostrar una escena lista.
  • Botones rapidos para cargar bobinado demo y alternar campo.
  • Tema oscuro verde/marron coherente con el laboratorio.
  • README tecnico nuevo y ficha de caso integrada.
