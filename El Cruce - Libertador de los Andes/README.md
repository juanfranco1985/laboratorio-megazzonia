# El Cruce · Libertador de los Andes

Juego 2D histórico inspirado en la preparación y el Cruce de los Andes. La versión 0.5.0, Expedición, transforma el recorrido en siete capítulos con identidades y mecánicas propias.

## Expedición v0.5.0

- El Plumerillo funciona como capítulo jugable: hay que reunir víveres, equipo y materiales antes de partir.
- El mundo asciende casi mil píxeles hasta la alta montaña y luego desciende hacia Aconcagua.
- La quebrada de Los Patos ya no se salta: la columna se reúne y construye un puente portátil visible y transitable.
- Cámara vertical con parallax, nuevos fondos de campamento y quebrada, y atlas de logística histórica.
- Siete capítulos: Preparación, Partida, Puente, Ascenso, Noche, Cumbre y Descenso.
- Guardado v2 con migración del progreso anterior y persistencia del estado de misión.

## Ejecutar

Desde esta carpeta: npm run dev. Luego abre la dirección local indicada por Vite.

## Controles

Movimiento: A/D o flechas. Salto y doble salto: W, flecha arriba o espacio. Interacción: E. Órdenes: 1 avanzar, 2 reagrupar, 3 descansar. Pausa: P o Escape.

## Verificación

Ejecuta npm test y npm run check.
